# P1-A 多起报气溶胶残差实验

## Material Passport

- 来源为 academic-research-suite / experiment-agent，实验设计。
- 版本为 P1A-20240726-20240801-v1。本地配对已检查，正式 GPU 结果待验证。

## 样本与对照

使用 2024-07-26 至 2024-08-01 每天 22:30 UTC 的 GEOS-FP 状态。冻结 3、6、9、12 h TorchScript 权重，保留完整 54 通道。主路径为 3、6、9、12、12+3、12+6、12+9、12+12 h。12 h 对照为 12、6+6、3+3+3+3、9+3、3+9，共享直达记录。预期 84 条唯一末端预测和 98 个唯一模型前缀。无缓存时每起报调用 14 次。

初始归一化采用 FP16 往返，模型接口及后续归一化状态为 FP32，按每步源时刻更新时间标签。参考为 M2T1NXAER。按解码 UTC 精确匹配次日 01:30 至 22:30 的八个时次。GEOS-FP 每两个索引取一，MERRA-2 只重排等价格点。GEOS-FP 气溶胶/高空为 3 h 平均、通量为 1 h 平均，MERRA-2 为 1 h 平均。残差 E=参考−预测，持续性残差 Eₚ=参考−物理初值。参考系统及平均窗差异可能进入残差。

模型通道以 get_vars、merra_norm.csv 和 info.pkl 联合校验。气溶胶 12 通道逐一同名映射，展示别名 AOD=TOTEXTTAU、DUAOD=DUEXTTAU、DUSMC=DUSMASS。SLP 在气象分组统计中算地面诊断量，但原始模型顺序保持在 QV_72 与 T_45 之间。

## 统计与判读

| 问题 | 预先固定的判读方式 |
|---|---|
| 相比持续性的技巧 | 同起报、同目标、同变量使用共同有限值掩码。给出逐日起报 Skill 及改善天数、分母、均值、中位数、范围和跨日起报标准差。分别给出日 RMSE 的算术均值及加权平方误差与面积合并后开根所得的 pooled RMSE。 |
| 空间及跨时效结构 | 沿用 P0 纬带和滞后相关定义。给出逐日起报曲线、同日起报跨时效场相关，以及 3、12、24 h 同时效跨起报的空间场相似度。用逐格有效样本数汇总均值、总体标准差和绝对残差均值。 |
| 尾部集中程度 | 按绝对残差排序，取 ceil(p×有效格点数)，固定格点顺序处理并列，计算面积加权平方量占比。输出 0.1%、1%、5%、10% 及累计曲线。另以预测值最高 1% 标记高预测区，报告它与高绝对残差区的重合。热点以逐格有效日期数为分母。 |
| 条件依赖 | 各变量、时效、路径和条件共用七天普通格点分位边界，合并重复边界。报告预报/起报与 E、绝对 E、E² 的加权 Pearson、逐日及合并的条件矩、分位数、有效格点数和面积。边界由本批次探索性估计，预报与残差有代数耦合。 |
| 多变量相关 | 用每对变量有限值交集计算面积加权 Pearson，报告逐日系数和跨日起报算术均值、标准差及有效天数。联合协方差和低维建模留待有独立天气过程的数据。 |
| 接力顺序 | 比较 12 h 路径准确性、两两场相关、预测差 RMS、差异相对平均预测 RMSE 的比值和排名。单独报告 3+9 与 9+3。复算残差差分恒等式。 |
| 非负性 | 分别检查有效参考和原始预测，记录负值频率、幅度及面积。仅比较终点截断前后全域与原负值区的 RMSE、MAE、Bias 和均值。 |
| P2 参数化 | 同域比较参考、持续性残差与 AI-GAMFS 残差的均值、中心化方差、加权平方范数、尾部和空间相关。固定变量与时效的七样本中心化秩至多 6。 |

面积权重为 cos(latitude)，极点权重为零。Bias、Std、MAE、RMSE 和 Pearson 加权，极值、分位数、偏度和超额峰度用普通格点。Skill 及相对路径差的分母低于配置中归一化标准差的相对阈值时保留缺测。七天逐日范围为观测范围。连续起报、格点、时效和路径均可能相关，结果限于短期描述性证据。

## 数据与阶段验收

运行目录按真实起报时刻分片。预测分片保留物理 54 通道及记录坐标。残差分片以参考索引去重同日起报的路径共享参考，持久化掩码和残差，持续性预报由初值索引提供。先验收数据、通道、单位、网格及 56 个目标时间，再在 Linux GPU 验收单个新增日期，最后完成批量和聚合。抽样独立复算面积加权 RMSE，并验收两个残差代数恒等式。

旧 P0 协议日期为 07-24，存档配置和 NetCDF 实际起报为 07-26 22:30 UTC。P0 三通道正式预测文件用于交叉验证。完整归一化前缀需经过来源、精度、代码、坐标和数值核对后才能导入。原结果作为只读证据。报告逐项对照 P0，并额外展示排除重叠起报后的六日结果。
